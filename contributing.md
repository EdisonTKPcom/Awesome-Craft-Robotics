# Contribution Guidelines

These guidelines are for [Awesome Craft Robotics](https://github.com/EdisonTKPcom/Awesome-Craft-Robotics).

Please note that this project is released with a [Contributor Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Adding an entry

- Search previous suggestions before making a new one, to avoid duplicates.
- The project must be open source, or clearly source-available with the licence noted in the description, and have a public repository.
- Use the format: `- [Name](https://github.com/owner/repo) - Short description.`
- Keep descriptions short, start with a capital letter, and end with a period.
- Flag non-OSI, source-available, archived or unmaintained projects in the description.
- Add the entry in alphabetical order within the right category.
- For GitHub-hosted projects, include a live shields.io star badge after the description, matching existing entries.
- Make one pull request per suggestion.
- Check your spelling and grammar, and remove trailing whitespace.
- Do not add brand logos or wordmarks to the banner or README artwork.
- Do not invent official repositories for closed products. Company claims, prices and ship dates belong in the description, tagged as goals, with a cited source.
- Running learned policies on real robots is a physical-safety matter. Mention that risk when an entry is meant to be deployed on hardware.

## Updating the list

Improvements to categories, removal of dead or unmaintained projects, and corrections are welcome. Open an issue or pull request.

Thank you for your suggestions!
